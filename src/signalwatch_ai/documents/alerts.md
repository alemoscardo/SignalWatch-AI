# Synthetic alert guide

## High temperature
Fictional document, revision 1. Possible explanations include increased load, insufficient cooling or sensor error. Compare temperature and speed before the alert. None of these explanations is a verified diagnosis.

## Suggested checks
Assessing cooling would require coolant flow and temperature measurements, which are absent from this demo. Assessing sensor error would require an independent measurement. A return below threshold only establishes recovery of the observed temperature, not resolution of a physical cause.
